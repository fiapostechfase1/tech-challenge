# 🍷 Análise de Exportações de Vinhos Brasileiros (2010–2024)

Este repositório apresenta uma análise descritiva e visual dos dados de exportação de vinhos do Brasil ao longo dos últimos 15 anos, com foco especial no mercado paraguaio, oscilações no valor médio por litro, impacto de fatores climáticos e barreiras comerciais.

---

## 📊 Sobre o Projeto

Este estudo foi desenvolvido como parte do **Tech Challenge**, com o objetivo de aplicar análise de dados reais em um contexto estratégico para o setor vitivinícola brasileiro.

O projeto explora:
- A evolução histórica do volume e valor exportado;
- O ranking dos principais países importadores;
- O cálculo do valor médio por litro exportado;
- A correlação entre a cotação do dólar e o desempenho das exportações;
- O impacto de eventos climáticos extremos, como as enchentes no RS em 2024.

---

---

## 🔍 Destaques da Análise

- 📈 **2013**: Maior receita da série histórica, impulsionada por políticas de escoamento para a Rússia  
- 💸 **2014**: Maior valor médio por litro exportado  
- 🌧️ **2024**: Queda severa na produção devido a eventos climáticos no Sul do Brasil  
- 🇵🇾 **Paraguai**: País mais rentável e consistente nas exportações recentes
